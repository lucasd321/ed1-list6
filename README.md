**PT-BR**
# TAD Lista Sequencial (MyArrayList)

Este repositório contém a implementação de um **Tipo Abstrato de Dados (TAD) Lista Sequencial** em Java, utilizando arrays. O foco do projeto é a definição da estrutura de uma lista que mantém elementos organizados de forma contígua na memória.

## 🚀 Objetivo do Exercício
Desenvolver a estrutura básica da classe `MyArrayList` contemplando as principais operações de um vetor dinâmico, como inserção, remoção, busca e atualização, além do controle de capacidade.

## 🛠️ Funcionalidades Estruturadas
A classe `MyArrayList` possui os seguintes atributos:
`item`: Array de inteiros para armazenamento.
`count`: Rastrear a quantidade de elementos inseridos, contador.
para os seguintes métodos:

* **Inserção:** `addFirst`, `addLast`, `insertAt`.
* **Remoção:** `removeFirst`, `removeLast`, `removeAt`, `remove`.
* **Busca e Acesso:** `find`, `get`.
* **Atualização:** `set`.
* **Exibição:** `display`.

**English**
# Sequential List ADT (MyArrayList)

This repository contains the implementation of a **Sequential List Abstract Data Type (ADT)** in Java, using arrays. The project focuses on defining the structure of a list that maintains elements organized contiguously in memory.

## 🚀 Exercise Objective
Develop the basic structure of the `MyArrayList` class, encompassing the main operations of a dynamic array, such as insertion, removal, search, and update, in addition to capacity control.

## 🛠️ Structured Functionalities
The `MyArrayList` class has the following attributes:
`item`: Integer array for storage.
`count`: Track the number of inserted elements, counter.

for the following methods:

* **Insertion:** `addFirst`, `addLast`, `insertAt`.

* **Removal:** `removeFirst`, `removeLast`, `removeAt`, `remove`.
* **Search and Access:** `find`, `get`.
* **Update:** `set`.
* **Display:** `display`.
